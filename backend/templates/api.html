API pública

JSON plano, sin claves ni cuotas para lectura. Los datos de salud son los mismos que ve el portal, con hasta 100 chequeos de historia por nodo.

Búsqueda

GET /api/search
curl -s "/api/search?q=biblioteca&status=online&page=1"

{
  "query": "biblioteca",
  "page": 1,
  "total": 2,
  "pages": 1,
  "engine": "local",
  "elapsed_ms": 3,
  "results": [
    {
      "url": "http://…onion",
      "domain": "…onion",
      "title": "Biblioteca Sombra",
      "description": "Archivo de textos sobre vigilancia…",
      "category": "Biblioteca",
      "uptime_ratio": 0.94,
      "avg_response_time": 0.71,
      "last_checked": "2026-10-26T00:12:00",
      "online": true
    }
  ]
}

Parámetros: q (obligatorio, ≤120 caracteres), category, status (todos|online|offline), sort (relevancia|uptime|latencia|reciente), page.

Nodos

GET /api/sites
curl -s "/api/sites?category=Foros&limit=25"

Devuelve hasta 100 nodos con su estado de salud. Sin autenticación.
